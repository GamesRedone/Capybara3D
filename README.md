## **Description**

Capybara 3D is a Vite/Three.js web application that allows you to customize the appearance of 3D characters through a point-and-click browser-based UI. Turning the Games Redone Character Asset Library into an interactive character creator that you can use anywhere.

This tool is utilized by Games Redone to allow members of the community to contribute unique characters to The Untold Path.

<br>

ℹ️ Currently, this repository is a direct clone of [CharacterStudio](https://github.com/M3-org/CharacterStudio) by the Atlas Foundation, with plans to expand its functionality.
> *[CharacterStudio Documentation](https://m3-org.github.io/characterstudio-docs/docs/about)*

## **Features**

- The Games Redone Character Asset Library
- Point-and-click character creation
  - Customization options for clothing and skin color
- Variety of programmable animations
- Robust Rendering
  - Powered by Three.js and WebGL
- One-click VRM optimization
  - Skinned mesh merging
  - Texture atlasing
- Character Exporter
  - Characters can be exported in `.glb` or `.vrm` format.
    - Screenshots can also be exported
  - Batch Export
    - Randomize or adhere to metadata schemas
